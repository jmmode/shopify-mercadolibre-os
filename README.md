# SHOPIFY Y MERCADO LIBRE — Ecommerce OS

Repositorio canónico de arquitectura, SOP, decisiones y automatizaciones para un modelo comercial híbrido: inventario propio y proveedores externos.

**Objetivo:** aumentar utilidad neta y reducir progresivamente la intervención humana sin perder control sobre stock, entregas, costos ni experiencia del cliente.

## Inicio
1. Leer [AGENTS.md](AGENTS.md).
2. Leer [documento maestro](00_GOBIERNO/ECOMMERCE_MASTER.md).
3. Consultar [estado](00_GOBIERNO/ESTADO_PROYECTO.md) y [decisiones](00_GOBIERNO/DECISIONES.md).
4. Revisar el expediente y SOP de cada producto antes de operar.

## Áreas
- 00_GOBIERNO: estrategia, decisiones, riesgos, control.
- 01_CANALES: Shopify y Mercado Libre.
- 02_CATALOGO: proveedores, inventario, márgenes.
- 03_PRODUCTOS: expedientes EP-V001, EP-V002 y posteriores.
- 04_OPERACIONES: procesos comerciales y postventa.
- 05_AUTOMATIZACIONES: integraciones y orquestación.
- 06_FINANZAS_Y_DATOS: indicadores y conciliación.
- 07_MARKETING: campañas y recursos.

GitHub es la fuente canónica del conocimiento operativo y técnico, **no** almacén de datos transaccionales ni de credenciales. La existencia de un documento no demuestra que una integración esté conectada o probada.
